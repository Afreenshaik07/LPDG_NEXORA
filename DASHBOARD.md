# NEXORA 2026 — Streamlit Dashboard

## Overview

The NEXORA 2026 Streamlit dashboard is the presentation layer for the
**LPDG Innovation Hub Gateway Visit Prioritization** solution.

It visualizes the final `predictions.csv` generated by the offline
Data Science pipeline and helps an operations user understand:

- which gateways are prioritized for field visits;
- the weekly ranking and priority score;
- why a gateway was selected;
- operational signals associated with the recommendation;
- weekly priority trends;
- field-service cost context.

The dashboard does **not** train a model or create a separate prediction.
It displays the output of the validated Data Science pipeline.

---

## Purpose

The operational problem is to select the most important gateways for
field visits when the field team has a fixed capacity of:

**15 visits per week**

The dashboard makes this decision easy to inspect visually.

The underlying decision flow is:

```text
Supplied Data
     ↓
Weekly Gateway Features
     ↓
Risk Calculation
     ↓
Weighted Visit-Priority Score
     ↓
Gateway Ranking
     ↓
Top 15 Gateways
     ↓
predictions.csv
     ↓
Streamlit Dashboard
